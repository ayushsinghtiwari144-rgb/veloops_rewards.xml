# VELOOP Rewards - Server

Express.js backend service for the VELOOP Rewards application.

## Getting Started

### Installation
```bash
npm install
```

### Environment Configuration
Copy `.env.example` to `.env` and set your local variables:
```bash
cp .env.example .env
```

### Run Server (Development)
```bash
npm run dev
```

### Run Server (Production)
```bash
npm start
```

## Available API Endpoints (Phase 1)
- `GET /api/health` - Health check status
