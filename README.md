## 📌 About The Project

VELOOP Rewards is a modern full-stack web application focused on creating an attractive and interactive rewards experience.

The project includes a polished and responsive user interface with multiple sections for rewards, earning activities, user progress, withdrawals, FAQs, roadmap information and more.

The frontend has been designed with a modern visual system, smooth interactions and responsive layouts to provide a consistent experience across different screen sizes.

🚀 Getting Started
1. Clone the repository
git clone https://github.com/ayushsinghtiwari144-rgb/veloops_rewards.git
2. Go to the project directory
cd veloops_rewards
3. Install frontend dependencies
cd client
npm install
4. Start the frontend
npm run dev
The development server will start locally.
🔧 Backend Setup
Go to the server directory:
cd server
npm install
Configure the required environment variables in your .env file according to the project configuration.
Then start the backend using the project's configured start command.
Do not commit private credentials, API keys, database URLs or authentication secrets to GitHub.
